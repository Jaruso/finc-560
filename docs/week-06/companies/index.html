Data and methods

Initial featured-company figures come from directly linked public annual reports and SEC 10-K disclosures, with the latest source linked for each company. The Microsoft FY2026 source is its official annual earnings release. These are verified snapshots; automated SEC refresh is paused while hosted-runner access returns 403. No synthetic company data are published.

Revenue forecasts use an OLS trend or a CAGR fitted to recent annual revenue. Operating and net margins use three-year recency-weighted historical averages. Growth adjustments compound relative to the selected baseline, while the margin adjustment changes both derived projected profit margins by the stated percentage points. This is a driver-based conditional projection, not a probability distribution or a complete integrated financial-statement model.

Fiscal-calendar differences and amendments affect comparability. The initial data are dated, and any future automated SEC refresh must pass all-source validation before replacing them. Forecasts are browser-calculated; no API key or invented historical data are published.
