Methodology, limitations & data sources

Audience and decision: Fixed-income analysts evaluating how assumptions about policy-rate changes and maturity-specific responses affect the shape of the Treasury curve. This is a what-if tool, not an investment recommendation.

Observed data: FRED DGS5, DGS10, and DFF. Each month uses the latest available reading for each series; the current month may be incomplete. Figures are annualized yield percentages; spreads are shown in percentage points or basis points as labeled.

Historical fit: For the selected lookback period, ordinary least squares calculates the contemporaneous relationship between monthly changes in DFF and monthly changes in each Treasury yield. This is not an identified causal response; markets anticipate policy, and term premia and other factors matter. Clicking “Use fitted response assumptions” rounds the diagnostics to the nearest 0.05×.

Scenario math: A user-selected cumulative rate shift is phased in linearly over the selected horizon. Each Treasury yield moves by its separate, editable response factor times the cumulative shift. The spread equals projected 10Y minus projected 5Y. A negative modeled spread is a hypothetical inversion, not a recession forecast. Estimated crossing time follows solely from this assumed linear path.

Corridor: The shaded ± basis-point spread corridor widens linearly to the user-selected terminal width. It is a sensitivity illustration, NOT a statistical confidence interval, probability of inversion, or prediction. This simplified model omits forward guidance, term-premium shocks, market expectations and macroeconomic feedback.

Reproducibility: The Python source retrieves the FRED series using the repository's existing cache/provider and publishes this site's JSON snapshot with a GitHub Actions refresh. No FRED API key or proprietary data is required.
