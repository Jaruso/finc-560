FINC 560

Assignment Visualizations

Status

Static pages for long-form Plotly output.

Site structure

Python assignment modules export Plotly figures into docs/visualizations/. The public site embeds each graph in a same-origin iframe so long charts can scroll naturally.

Publishing target

GitHub Pages can serve this repository directly from the docs folder on main.

Workflow

Add a weekly assignment module, then export.

  1. Create or copy a file in src/assignments/.
  2. Add Plotly figures to its FIGURES list.
  3. Run python scripts/export_plotly.py.
  4. Commit the updated source and generated docs/ output.
